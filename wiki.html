CHAPTER 01

IDENTITY & SCOPE

CINEK is the artist name associated with the linked music catalogue. This wiki describes the masked visual reference supplied for this fan-made website. It is not an official character bible, biography, or artist statement.

Do not assume that every video, lyric video, promotional image, or collaboration depicts the same masked performer. Confirm each visual from its original source.

CHAPTER 02

RECOGNIZABLE FEATURES

Source-observed cues: dark hood or head covering, black fabric obscuring the lower face, prominently framed eyes, tight portrait crops, and a subdued cinematic mood.

Not verified: uncovered facial appearance, age, physical identity, fixed eye color across lighting, exact garment brand, tattoos, or canonical backstory. Avoid inventing those as facts.

CHAPTER 03

KEEP THE CHARACTER CONSISTENT

  1. Start from an authorized reference image, not an invented unmasked face.
  2. Maintain a dark fabric face covering and eye-focused composition.
  3. Specify lighting and camera placement; keep these stable across related frames.
  4. Change one variable at a time: setting, pose, or color treatment.
  5. Reject outputs that expose unverified facial features or add logos.
  6. Label resulting images as fan-made interpretations, not official stills.

CHAPTER 05

IMAGE & VIDEO WORKFLOW

  1. Browse the reference looks and inspect source labels.
  2. Choose a scene in CREATE CINEK.
  3. Add a brief environment, camera, and mood description.
  4. Copy the image prompt into an external image tool with a reference you are authorized to use.
  5. For video, use the motion prompt and a consistent starting image.
  6. Review for visual continuity and disclose that it is fan-made.

The site supplies prompts and guides. It does not host an image/video generator or license character rights.
